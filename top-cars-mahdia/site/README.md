# Top Car Mahdia — website

One-page French site for Top Car, a car rental, airport transfer and excursion agency in Mahdia, Tunisia (avenue Taher Sfar). Built with Vite + React 19 + Tailwind 4, on the same architecture as `di-piu/site` and `hlila-rent-car/site`.
The design follows the Stitch concept and `../stitch/desktop-final.html` ("Charcoal & Signal Red": charcoal #1E1F22 / #141517 and signal red #E3202B from the agency's logo and post band; Barlow Condensed, Hanken Grotesk and Space Mono).

Booking is a WhatsApp request only: no booking engine, payments, accounts or backend.

**Live:** https://top-cars-mahdia.vercel.app (Vercel project `top-cars-mahdia`).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check, client build, SSR build, prerender → dist/
npm run preview    # serve dist/ on http://localhost:4173
```

**Before deploying:** `.env` must contain `SITE_URL=https://top-cars-mahdia.vercel.app`, or the real domain if that changes. It is used for the canonical URL, sitemap, llms.txt and JSON-LD.

## Where things live

| File | Purpose |
| --- | --- |
| `src/data/agency.ts` | **Every fact on the site**: contact details, hours, fleet (models and body type), services, pick-up suggestions, gallery, reviews, FAQ. Edit here only. |
| `src/data/photos.json` | Photo sizes and available widths, generated by `../_scratch/optimize_photos.py` |
| `public/photos/` | Self-hosted WebP photos (`<id>-<width>.webp`, 640/1024/1600, hero also 2400) and `og.jpg` (1200×630) |
| `src/components/Header.tsx` | Fixed header and mobile drawer |
| `src/components/Hero.tsx` + `RequestBar.tsx` | Hero and the WhatsApp request bar (service, pick-up place, dates, vehicle; validates that the return is after the pick-up) |
| `src/components/Fleet.tsx` | Filter chips (ARIA toolbar) and one typographic row per model with a "Demander ce véhicule" WhatsApp link |
| `src/components/Sections.tsx` | Red slogan band, Services, How to book, Excursions gallery, Reviews, final CTA |
| `src/components/Contact.tsx` | FAQ, Contact (lazy map, hours), Footer, phone ActionBar |
| `src/seo/seo.ts` | Head tags, JSON-LD, robots.txt, sitemap.xml and llms.txt, all generated from the data file |
| `vite.config.ts` | `top-cars-mahdia-seo` plugin: injects the head tags and emits robots/sitemap/llms (also served in dev) |
| `scripts/prerender.mjs` | Renders the app to static HTML after the build |

## Responsive

- **Phones (< 1024px):** full-screen hero with the photo behind the text and the request bar stacked under the headline; ☰ drawer with links, hours and phone; fleet filter chips stick under the header and scroll sideways; fixed Call · WhatsApp · Directions bar once the hero scrolls away. Checked at 375px (no horizontal overflow).
- **Desktop:** 900px hero (photo on the right 62%, request bar in one row along the bottom), typographic fleet table, 12-column gallery.

## SEO / GEO

- **Prerendered HTML** lists the whole fleet (filtered models are `hidden`, not removed), the services, reviews and FAQ. React hydrates it for the filters, request bar, drawer and action bar.
- **JSON-LD `@graph`:** `WebSite`; `AutoRental` with address, geo, Mon–Sat 09:00–19:00 hours, phone, email, `sameAs` (Google Maps, Facebook) and an `OfferCatalog` of services and fleet **without prices** (none are published, so no `makesOffer` prices); `FAQPage`. Google ratings are shown but not marked up (self-serving review markup is ignored by Google).
- **Crawler files:** `/llms.txt` fact sheet; `robots.txt` allowing search and AI crawlers; `sitemap.xml` with image entries.
- **Local signals:** `geo.region` TN-53, `geo.position`, ICBM, Open Graph `business.business` with contact data, Twitter card, preloaded hero with `srcset`.

## Known limitations / owner to confirm

- **No car photos:** every car image on the agency's Facebook is a promo flyer (text over manufacturer/stock visuals), so the fleet is typographic and the imagery is real customer excursion photos from Google Maps. 5–10 plain photos of their own cars would improve the fleet section.
- **Fleet:** models from their Facebook posts (2023–2025); transmission, fuel and seats are not published ("jusqu'à 9 places" for the van comes from Google reviews).
- **Prices and rental conditions:** none published → "Prix sur demande" everywhere, no Conditions section.
- **Hours:** Google says Mon–Sat 9–19, Sunday closed; reviews mention night airport transfers — confirm whether transfers run outside opening hours.
- **Airports served:** Monastir and Sfax (photo + reviews); Enfidha unknown. No self-drive car delivery is stated, so the airport pick-up suggestion only appears for transfers.
- **Not on the site yet:** landline 73 653 271 (Facebook only) and an Instagram "TOPCAR" whose handle wasn't found.
- **After launch:** submit the sitemap in Google Search Console and add the website link to the Google Business Profile.
