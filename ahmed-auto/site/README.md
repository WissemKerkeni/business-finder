# AHMED AUTO — website

One-page French site for AHMED AUTO, a showroom of new and used cars on the Route de Monastir in Ksibet El Mediouni (Monastir, Tunisia). Built with Vite + React 19 + Tailwind 4, on the same architecture as `top-cars-mahdia/site`.
The design follows `../stitch/desktop-final.html` and the Stitch render `../stitch/desktop-v1-stitch-render.png` ("Graphite Showroom & Logo Red": near-black #0D0D0F, graphite #16171A, one red accent #C4121E from the logo; Anybody wide, Hanken Grotesk, JetBrains Mono).

It is an informational showroom: an enquiry is a WhatsApp message or a phone call. No sales, payments, accounts, reservations or backend.

**Live:** https://ahmed-auto.vercel.app (Vercel project `ahmed-auto`, `prj_Ok4T7acPfxpfspMAThZZMDkCTmcJ`, team `team_ODIYw5HwL1ZT6MkftJt0ZpW3`; first production deploy `dpl_7peDNYBiTMUTbvxJPZ1n1Jr3sRQJ` on 2026-09-28). `SITE_URL` is set in the Vercel production env; deploy from this folder with `npx vercel deploy --prod --yes`.

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check, client build, SSR build, prerender → dist/
npm run preview    # serve dist/ on http://localhost:4173
```

**Before deploying:** `.env` must contain `SITE_URL=https://ahmed-auto.vercel.app` (or the real domain). It is used for the canonical URL, sitemap, llms.txt and JSON-LD.

## Updating the stock

The stock is a dated snapshot of the dealer's posts, never a live inventory.

1. **Edit `src/data/dealer.ts`**: add, change or remove a car in `stock`. Copy only what the dealer's post says (year, mileage, fuel, CV, colour, options). Leave unknown values `null`. Never guess a spec or a price. Remove sold cars.
2. **Add photos**: put the originals in `../_scratch/kept/<car-id>-01.jpg … -NN.jpg` (blur readable number plates first, see `../_scratch/prep_photos.py`), set `photos: N` on the car, add alt texts in `altBase`, then run `python ../_scratch/optimize_photos.py` to regenerate `public/photos/` and `src/data/photos.json`.
3. **Bump `stockDate`** in `dealer.ts` (it appears in the hero, the stock header, the footer, the FAQ and llms.txt).
4. `npm run build`, check with `npm run preview`, then redeploy: `npx vercel deploy --prod --yes`.

## Where things live

| File | Purpose |
| --- | --- |
| `src/data/dealer.ts` | **Every fact on the site**: contact details, hours text, stock (specs, stated options, post date and post URL per car), gallery, buying steps, reviews, FAQ, stock date, WhatsApp message. Edit here only. |
| `src/data/photos.json` | Photo sizes and available widths, generated by `../_scratch/optimize_photos.py` |
| `public/photos/` | Self-hosted WebP photos (`<id>-<width>.webp`, 640/1024/1600, hero also 2400), plates blurred; `og.jpg` (1200×630) |
| `src/components/Header.tsx` | Fixed header and phone drawer |
| `src/components/Hero.tsx` | Full-height hero (showroom photo, rating, stock date, CTAs) |
| `src/components/Stock.tsx` | Filter chips (ARIA toolbar: make, energy), sort (newest, year, mileage), counter, one row per car. All cars are rendered; filtered ones are `hidden`, so the prerendered HTML has the full stock |
| `src/components/CarDialog.tsx` | Car sheet: focus-trapped dialog (Esc closes, focus returns), carousel with arrows/swipe/thumbnails/counter, spec table, stated options, WhatsApp/Call |
| `src/App.tsx` | Page layout and `#car-<id>` hash routing (a link opens its car sheet) |
| `src/components/Sections.tsx` | How to buy, Showroom gallery, Reviews, FAQ, Location (lazy map), CTA band, Footer, phone ActionBar |
| `src/seo/seo.ts` | Head tags, JSON-LD, robots.txt, sitemap.xml and llms.txt, all generated from the data file |
| `vite.config.ts` | `ahmed-auto-seo` plugin: injects the head tags and emits robots/sitemap/llms (also served in dev) |
| `scripts/prerender.mjs` | Renders the app to static HTML after the build |

## Responsive

- **Phones (< 1024px):** full-screen hero with the photo behind the text; ☰ drawer with links, hours and both phones; filter chips stick under the 64px header and scroll sideways, sort in a compact select; car rows stacked (photo on top); the car sheet is full-screen; a fixed Call · WhatsApp · Directions bar appears once the hero scrolls away. Checked at 375px (no horizontal overflow).
- **Desktop:** hero photo on the right ~72% with a scrim under the text; car rows with a large photo on the left and the spec block on the right; car sheet as a large overlay.

## SEO / GEO

- **Prerendered HTML** lists all 7 cars with their specs, the reviews and the FAQ. React hydrates it for filters, sort, the car sheet, the drawer and the action bar.
- **JSON-LD `@graph`:** `WebSite`; `AutoDealer` (address, geo, hours as stated by Google, both phones, email, `sameAs` Google Maps/Facebook/Instagram); an `ItemList` "Stock publié au …" with one `Car` (the quad as `Vehicle`) per car: brand, model, `dateVehicleFirstRegistered`, `mileageFromOdometer` (KMT), fuel type, transmission, body type and colour only where the post states them. **No `Offer`**, because no price is published. `FAQPage`. Google ratings are shown but not marked up (Google ignores self-serving review markup).
- **Crawler files:** `/llms.txt` with the dated stock; `robots.txt` allowing search and AI crawlers; `sitemap.xml` with image entries (hero, each car's cover, gallery).
- **Local signals:** `geo.region` TN-52, `geo.position`, ICBM, Open Graph `business.business` with contact data, Twitter card, preloaded hero with `srcset`.
