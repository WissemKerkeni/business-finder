# Hlila Rent Car — website

One-page French site for Hlila Rent Car, a car rental agency in Monastir, Tunisia. Built with Vite + React 19 + Tailwind 4, on the same architecture as `di-piu/site` and `dar-zmen/site`.
The design follows the Stitch concept and `../stitch/desktop-final.html` ("Asphalt & Swoosh Red": asphalt #0E0F11, red #E01B1B from the logo swoosh, sand #F4DDA0 from the logo badge; Barlow Condensed, Hanken Grotesk and Space Mono).

Booking is a WhatsApp request only: no booking engine, payments, accounts or backend.

**Live:** https://hlila-rent-car.vercel.app (Vercel project `hlila-rent-car`).

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # type-check, client build, SSR build, prerender → dist/
npm run preview    # serve dist/ on http://localhost:4173
```

**Before deploying:** `.env` must contain `SITE_URL=https://hlila-rent-car.vercel.app`, or the real domain if that changes. It is used for the canonical URL, sitemap, llms.txt and JSON-LD.

## Where things live

| File | Purpose |
| --- | --- |
| `src/data/agency.ts` | **Every fact on the site**: contact details, fleet (models, body type, stated transmission, photos), pick-up options, delivery, gallery, reviews, FAQ. Edit here only. |
| `src/data/photos.json` | Photo sizes and available widths, generated by `../_scratch/optimize_photos.py` |
| `public/photos/` | Self-hosted WebP photos (`<id>-<width>.webp`, 640/1024/1600, hero also 2400) and `og.jpg` |
| `src/components/Header.tsx` | Fixed header and mobile drawer |
| `src/components/Hero.tsx` + `RequestBar.tsx` | Hero and the WhatsApp request bar (pick-up place, dates, car; validates that the return is after the pick-up) |
| `src/components/Fleet.tsx` | Filter chips (ARIA toolbar), one row per car, tap-to-cycle photos, "Demander cette voiture" WhatsApp links |
| `src/components/Sections.tsx` | How to book, Delivery, Gallery, Reviews, final CTA |
| `src/components/Contact.tsx` | FAQ, Location (lazy map), Footer, phone ActionBar |
| `src/seo/seo.ts` | Head tags, JSON-LD, robots.txt, sitemap.xml and llms.txt, all generated from the data file |
| `vite.config.ts` | `hlila-rent-car-seo` plugin: injects the head tags and emits robots/sitemap/llms (also served in dev) |
| `scripts/prerender.mjs` | Renders the app to static HTML after the build |

## Responsive

- **Phones (< 1024px):** full-screen hero with the request bar stacked under the headline; ☰ drawer with links, hours and phones; fleet filter chips stick under the header and scroll sideways; fixed Call · WhatsApp · Directions bar once the hero scrolls away. Checked at 375px (no horizontal overflow).
- **Desktop:** 900px hero with the request bar in one row, photo-left fleet rows, 12-column gallery mosaic.

## SEO / GEO

- **Prerendered HTML** lists the whole fleet (filtered cars are `hidden`, not removed), the reviews and the FAQ. React hydrates it for the filters, photo cycling, request bar, drawer and action bar.
- **JSON-LD `@graph`:** `WebSite`; `AutoRental` with address, geo, 24/7 hours, phones, email, `areaServed`, `sameAs` (Google Maps, Facebook, Instagram) and an `OfferCatalog` of the fleet **without prices** (none are published, so no `makesOffer` prices); `FAQPage`. Google ratings are shown but not marked up (self-serving review markup is ignored by Google).
- **Crawler files:** `/llms.txt` fact sheet (fleet, delivery, reviews, FAQ); `robots.txt` allowing search and AI crawlers; `sitemap.xml` with image entries.
- **Local signals:** `geo.region` TN-52, `geo.position`, ICBM, Open Graph `business.business` with contact data, Twitter card, preloaded hero with `srcset`.

## Known limitations / owner to confirm

- **Prices:** none published anywhere → "Prix sur demande" everywhere.
- **Address:** Instagram says "derrière la municipalité"; a company registry lists "8 Immeuble Bab El Sour" and Infobel "9 Rue Essour". Google only has "Monastir 5000" / plus code QRFM+F9.
- **Hours:** "24h/24" comes from Google and the agency's own "Service client 24/24" caption; confirm for pick-ups and returns.
- **Transmissions:** from the Nov 2024 flyers; Skoda Scala and Mahindra XUV300 unknown. Kia Picanto (2024 flyers) and VW Polo (photos only) are left out.
- **Photos:** real photos from the agency's Google, Facebook and Instagram; some were taken at dealer delivery centres and are cropped to the car. Kushaq and Scala have no photo yet.
- **Airport:** which airport(s), and any delivery fee.
- **After launch:** submit the sitemap in Google Search Console and add the website link to the Google Business Profile.
